- DevTools CLI/CDP fue rechazado: no reintentar ni eludir. Solo fixtures Playwright Electron autorizadas sobre EXE empaquetado con perfiles propios. También se rechazó sustituir window.fetch en las fixtures: no reintentar ni eludir; spec93 usa servidor HTTP local y webRequest solo en el salto de main, preservando el protocolo/proxy real.
