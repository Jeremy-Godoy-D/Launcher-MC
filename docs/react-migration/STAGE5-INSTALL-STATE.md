# Etapa 5 parcial — publicación segura del estado de instalación

Fuente `cf2b77d`, 2026-10-27. Corrección del escritor compartido de perfiles/locks de instalación antes de conectar actualizaciones de mods. No cierra K08 ni gates5.

El nombre temporal fijo podía existir como enlace duro a otro archivo: escribirlo truncaría ese otro archivo. Ahora se crea un temporal adyacente con UUID y apertura exclusiva `wx`, se escribe y cierra antes de publicar mediante rename, y se elimina únicamente ese temporal propio ante fallo. Se rechazan padres directos enlazados/no directorio, destinos no regulares y estados no serializables. Se conservan el JSON con salto de línea, los esquemas de datos y los reintentos Windows existentes.

Las cinco pruebas nuevas usan archivos reales: enlace duro plantado en el antiguo `.tmp` sin modificar su destino; lector que observa el estado completo anterior hasta publicar el reemplazo completo; directorio enlazado/destino no regular; valores no serializables y fallo IO al publicar con conservación del original y limpieza del temporal. Los26 casos existentes de instalación progresiva/concurrente siguen pasando. Un estrés inicial de escritores solapados produjo EPERM de Windows; no se añadió una cola global ni se prometió ese contrato. Los escritores del instalador se serializan mediante sus locks existentes; la prueba final comprueba el contrato del lector antes de publicación. Los logs de diagnóstico fallidos permanecen retenidos.

Se recompilaron los hosts con los renderers existentes, sin cambios visuales, y se restauró dist/default Vue. La corrección no autoriza rutas arbitrarias, ni valida todos los ancestros ni convierte el instalador completo en una transacción o garantía frente a pérdida de energía.
