## Comportamiento implementado

El diálogo diferencia archivo, enlace HTTPS y carpeta existente. El enlace requiere pulsar **Revisar enlace**: escribir no descarga ni crea instancias. Se rechazan protocolos distintos de HTTPS, credenciales, fragmentos, controles y entradas mayores de 4096 caracteres. Cada revisión adquiere un estado nuevo; se reutiliza `ModpackService.openModpack` y su descargador temporal existente. El mismo enlace puede revisarse otra vez tras un fallo sin reutilizar una descarga antigua. Confirmar sigue siendo un paso separado.

La importación de carpeta permite escoger formato y perfil Vanilla, Prism/MultiMC estándar, Modrinth App o CurseForge App. Muestra la ruta efectiva y el número de archivos. `InstanceIOService.previewFolderFiles` hace un inventario de solo lectura en main: hashes SHA-1/SHA-256 por streaming, máximo 64 niveles y 100000 entradas; rechaza raíz de disco, enlaces/junctions, archivos especiales y destinos ambiguos. La validación del renderer también rechaza rutas peligrosas y nombres reservados de Windows antes de crear. Se excluyen metadatos de cuentas/launcher/instalación, logs y cachés compartidas de Minecraft/Java.

Los archivos se confirman mediante el manifiesto de instalación existente. Las fuentes `file:` se copian en lugar de compartir inodos con el original: la prueba modifica el mundo de destino y comprueba que el origen no cambió. La configuración importada conserva solo los campos permitidos de identidad/runtime y metadatos públicos; no adopta Java, memoria, comandos ni argumentos del perfil externo. Las preferencias de carpetas compartidas no se aplican a ninguna importación.

La creación manual añade descripción, autor, Java automático/registrado/ejecutable elegido, memoria heredada/automática/manual y los cinco enlaces compartidos anteriores: mundos, resource packs, shaders, opciones y servidores. La RAM exige enteros válidos y mínimo no mayor que máximo. Se reutiliza el selector/resolución nativo de Java; elegir uno no lo descarga ni inicia Minecraft. El lanzamiento mantiene la comprobación de compatibilidad y la instalación automática del bloque anterior.

`addInstanceLinkPreferences` conserva su clave y versión anteriores. Se leen preferencias antiguas, se sincronizan entre ventanas y no se sobrescriben valores corruptos/futuros o almacenamiento inaccesible. El helper puro de enlaces se comparte con Vue; se conservan sus regresiones. Un fallo enumera enlaces pendientes, conserva la instancia y permite reintentar sobre la misma ruta con las operaciones nativas idempotentes. Cerrar/reabrir conserva los campos del diálogo y la selección de carpeta mientras vive la ventana; el origen se vuelve a revisar. No equivale a persistir el borrador tras destruir el renderer.
