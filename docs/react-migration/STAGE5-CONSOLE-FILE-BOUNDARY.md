InstanceLogService exige ahora una instancia Java registrada para listar, leer, retirar, abrir archivos y consultar su historial. No fuerza el registro de carpetas recibidas por IPC. Los lectores directos de cliente/servidor/crashes solo admiten nombres simples y extensiones de logs; rechazan traversal, rutas externas, ADS/dispositivos y enlaces. Los helpers del servicio usan métodos privados reales (`#`), inaccesibles por ServiceChannels. Se conserva ALL_PARAMS y la independencia de solicitudes del bloque anterior.

El helper localLogs limita a 16 MiB tanto la entrada como la salida de gunzip, y a 10.000 entradas la enumeración mediante opendir. Comprueba directorios y archivo regular, rechaza hard links, compara identidad del descriptor abierto y vuelve a comprobar la ruta tras leer. Permite append de un log vivo: devuelve solo la instantánea inicial acotada. Un archivo ausente sigue devolviendo vacío; permisos, corrupción, cambios y límites producen errores reconocibles sin incluir detalles originales del sistema. Las eliminaciones solo ignoran ENOENT. La apertura en Explorer valida primero el archivo y devuelve Promise<void>.

Compatibilidad: las raíces registradas pueden usar alias; se trabaja sobre su ruta física. Las ubicaciones absolutas de crash legacy solo se aceptan dentro de crash-reports de esa instancia o de su servidor. Los callers Vue conservan el fallback del informe capturado y muestran fallo de acceso en lugar de dejar promesas rechazadas sin tratar. HomeLogDialog reutiliza el notificador existente. El flujo de servidor que ya toleraba la ausencia de latest.log conserva su política previa.

React muestra fallos de listas/lectura/apertura con instrucciones de recuperación. Conserva listados disponibles si falla la otra categoría, ignora respuestas de archivo obsoletas y vuelve a leer el archivo seleccionado al pulsar Actualizar. Las capturas revelaron etiquetas sr-only sin regla CSS, que separaban el buscador de su etiqueta y ocupaban otra fila: c4a8b77 aplica el patrón de ocultación accesible ya usado por la biblioteca, acotado a la barra de consola.
