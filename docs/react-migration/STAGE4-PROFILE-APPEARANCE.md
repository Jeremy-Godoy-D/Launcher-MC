Fuente: `fa9fff56cb208bea7ef3ad6618b0569b37172e2c`, Windows x64, 2026-10-26. React permite elegir/restablecer skin, cambiar modelo clásico/slim y elegir/retirar capa de un perfil local, incluso si otro está activo. Reutiliza el puente tipado y los estados/servicios existentes. Conserva nombre, UUID de juego, selección, otros perfiles y mundos. Microsoft continúa pospuesto; las cuentas externas permanecen intactas.

Main incorpora `setLocalProfileAppearance`: vuelve a consultar la identidad y autoridad actuales, acepta archivos locales/`file:` y rechaza nuevas URLs remotas, rutas relativas y UNC. Valida PNG por firma/cabecera, dimensiones —skin 64×32/64×64; capa 64×32— y límite de 1 MiB durante lectura. No pretende implementar un decodificador PNG completo. Guarda bytes propios mediante ImageStorage, sin subirlos a un servicio. Modelos admitidos son booleanos explícitos; null restablece skin, cadena vacía retira capa y undefined conserva el campo. Tras leer los archivos, comprueba que el perfil/texturas sigan vigentes antes de una única mutación. Un error de capa no aplica parcialmente una skin; una eliminación concurrente no resucita perfiles.

La prueba de reinicio descubrió una incompatibilidad previa: la carga normaliza `OFFLINE` a `x://OFFLINE@dev`, mientras login y selección guardaban la forma anterior. Login usa ahora la misma identidad canónica, espera la inicialización y conserva los perfiles y texturas existentes al volver a añadir uno. Se retira el recálculo de UUID de perfiles persistidos: esos UUID identifican datos de partidas. React reconoce únicamente la equivalencia exacta del identificador local antiguo y guarda su forma canónica. Una selección externa o ausente no tiene sustitución silenciosa. Esta equivalencia no usa URL en renderer: en Chromium/Windows, `x://dev` se interpreta como `file:///X://dev`, a diferencia de Node; una captura de diagnóstico aislada reprodujo esa diferencia.

También se reprodujo un problema de propiedad de imágenes antiguas: una entrada de ImageStorage podía ser un enlace duro al archivo original. La prueba falló con nlink=2 antes del arreglo. Al recibir bytes validados, ImageStorage reemplaza atómicamente entradas enlazadas; conserva la reutilización de archivos propios y el comportamiento existente de importación por ruta. La prueba empaquetada siembra ese enlace antiguo y verifica que modificar/borrar los originales no altera las texturas guardadas.

El editor usa Radix, tokens y cristal existentes, con campos desplazables por teclado y acciones fuera del scroll. Conserva el borrador ante error; el aviso se desplaza a la vista sin robar foco. Si desaparece el perfil, desactiva Guardar y ofrece recuperación. Escape/cancelar cierran sin guardar y devuelven foco; durante guardado no cierran accidentalmente. Textos nuevos ES/EN.
